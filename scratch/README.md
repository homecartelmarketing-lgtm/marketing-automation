# Scratch Directory

This directory is strictly for throwaway scripts, temporary experiments, and one-off debug files.

## Guidelines
- **Not committed to git**: The `scratch/` directory is in `.gitignore` and should never be used for production code, long-term tools, or assets.
- **Permanent operational tools**: Scripts intended for operational maintenance, auditing, or schema provisioning should be located in `scripts/ops/`.
- **Pre-flight / Previewers**: Visual layout previewers should be placed in `scripts/previews/`.
- **Scrapers**: Data scrapers should be located in `scripts/scrapers/`.
