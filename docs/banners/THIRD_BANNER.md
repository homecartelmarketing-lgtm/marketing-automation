# Third Banner (1800 x 600): Sale-colour panel + Krea bedroom

The third banner of the **Banner Set** ([`BANNER_SET.md`](BANNER_SET.md)). It is made after the Christmas banner and the Sale banner, on the **same Airtable row**, and its panel uses the colour the Sale banner used (`Sale Panel Color`, chosen by Claude through fal.ai).

- **Layout (Canva sample, page 1800 x 600):** a solid panel on the **left, 951 x 600**, with the title, the subtitle and an arrow; the Krea bedroom on the **right, 849 x 600**.
- **Text:** `New Collection` (Poppins Medium 70 pt; Canva's B toggle renders Medium), `Free Delivery and Installation` (Poppins Regular 24 pt), both white, plus a white arrow. The text is fixed; override with `THIRD_BANNER_TITLE` / `THIRD_BANNER_SUBTITLE` or the CLI. Longer custom text shrinks to stay inside the panel.
- **Right image:** always a **modern bedroom with a Christmas vibe**, generated by Krea (short prompt, the moodboard carries the look) with **2 table lamps** blended in by Nano Banana Pro, one on each bedside table.
- **Script:** `generate_third_banner_pipeline.py`. It never creates a row: its CLI needs the `--record-id` of a row the Banner Set made. **Studio:** part of the Banner tab's single "Banner Set" run (phases 12-15 of 15).

## Phases

The numbers are the ones the script prints (`[PHASE 2]` to `[PHASE 5]`); the Studio shows them as 12-15 after the Christmas (2-6) and Sale (7-11) phases.

| # | Phase | Detail | Airtable |
| :-- | :-- | :-- | :-- |
| 1 | (the Set's scrape) | The Banner Set's Phase 1 also scrapes the two table lamps, codes `BA` and `BB` (Shopify-active, base-wide dedup, different from every other product of the row). | `Furniture Item` (BA, BB cutouts), `SKU`, `Item Name` |
| 2 | Krea | `krea-2`, **3:2** (retries at 4:3), 1K, "Generate me a modern bedroom with a Christmas vibe", moodboard `KREA_MOODBOARD_ID_THIRD_BANNER` (until it is set, the bedroom moodboard the Sale banner used, `fb2487fb-...`). | `Bedroom Interior`, `Bedroom Interior Prompt` |
| 3 | Claude | Claude Sonnet 5 vision studies the bedroom and the two lamps and writes the blending prompt (same stages and validation as the other banners; one lamp on each bedside table). Falls back to a fixed prompt. | `Bedroom Blending Prompt` |
| 4 | Nano Banana Pro | `fal-ai/nano-banana-pro/edit`, 3:2, 2K: `[bedroom, lamp A, lamp B]`. | `Bedroom Blended` |
| 5 | Composite | Local Pillow, zero API cost: the Sale colour panel, text and arrow, the bedroom cover-fitted into its 849 x 600 slot. Writes `Status = Done` and `Date and Time Generated`. | `Third Banner` (final) |

Local copies: `output/third_banner/bedroom_blend_<rec>.jpg` and `third_banner_<rec>.jpg`.

## Layout spec (measured on the Canva sample, design px)

| Element | Value |
| :-- | :-- |
| Panel | x 0-951, full height, `Sale Panel Color` (the sample red `(255, 49, 49)` only if the row has no usable colour) |
| Photo | x 951-1800 (849 x 600), cover-fit |
| Title | Medium 70 pt = 93.3 px, tracking -0.09 em, ink x 46.4-624.8 (578 px wide), ink y 394.7-465.6 |
| Subtitle | Regular 24 pt = 32 px, tracking -0.072 em, ink x 46.4-423.5 (377 px wide), ink y 483.9-515.7 |
| Arrow | 3 px line x 44-203 at y 554.8, chevron head (arms 12.5 px back, 6 px out), ink y 547.5-560.9 |

The constants are `THIRD_*` in `content_automation/overlay.py` (`draw_third_banner`); the unit test checks the measured ink boxes against the Canva numbers.

## Configuration

| Key | Purpose |
| :-- | :-- |
| `KREA_MOODBOARD_ID_THIRD_BANNER` | Krea moodboard for the bedroom (optional; default: the Sale banner's old bedroom moodboard). |
| `THIRD_BANNER_PROMPT` | Krea prompt override (default: "Generate me a modern bedroom with a Christmas vibe"). |
| `THIRD_BANNER_TITLE` / `THIRD_BANNER_SUBTITLE` | Panel text (defaults: "New Collection" / "Free Delivery and Installation"). |
| `THIRD_BANNER_RESOLUTION` | `1K`, `2K` (default) or `4K` for the bedroom blend. |

## CLI

```bash
# all three banners on one new row (what the Studio runs)
python generate_banner_set_pipeline.py --third-moodboard-id <id> --third-title "Holiday Collection"

# redo part of the third banner on a row the Banner Set made
python generate_third_banner_pipeline.py --record-id recXXXX --from-phase 4
python generate_third_banner_pipeline.py --record-id recXXXX --only-phase 5 --title "New Collection"
```

Run without `--record-id`, the script refuses and points to the Banner Set, so it can never add a row of its own.
