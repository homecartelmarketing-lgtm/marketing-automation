# Why 'Moodboard V1 Blended' and 'Moodboard Added Watermark' Both Receive YOLO Item Tags

## The Rule

In the **Moodboard #1 Feed Pipeline**, the raw room blend generated by Fal AI Nano Banana Pro is tagged with the product name and category via local zero-cost YOLO-World object detection **before** being attached to Airtable.
- **`Moodboard V1 Blended` (Slide 1)**: Holds the room blend with the floating product badge (`Poppins-Bold` item title + `Poppins-Light` category).
- **`Blended Image with Name text`**: Holds the identical tagged composite for cross-pipeline schema consistency.
- **`Moodboard Added Watermark` (Slide 2)**: Takes the tagged `Moodboard V1 Blended` image and stamps the official HomeCartel logo in the bottom-left Canva box ($190.3 \times 63.5\text{ px}$ @ $108.0, 1178.5$), ensuring Slide 2 showcases both the product name badge and brand logo.

## Why

Previously, `generate_moodboard_1_feed.py` attached the raw, untagged blend to `Moodboard V1 Blended`, while uploading the tagged image only to `Blended Image with Name text`. Because the Instagram carousel sequence defines Slide 1 as `Moodboard V1 Blended` and Slide 2 as `Moodboard Added Watermark`, viewers saw no product identification on either lifestyle slide.

By running YOLO tagging prior to the `Moodboard V1 Blended` upload:
1. Slide 1 immediately identifies the featured product to social media viewers.
2. Slide 2 preserves the product identification while adding the formal brand mark.
3. The brand logo (bottom-left) and the lighting fixture badge (near the ceiling or center table) occupy completely separate screen zones, preventing visual overlap.
